# Displace Agent Guide

## Project State

- This repository is an early scaffold. Treat [README.md](README.md) as the source of truth for product intent.
- Do not assume a language, framework, package manager, build command, or deployment topology until it is added to the repository or explicitly requested.
- `repos/` and `docs/` are reserved directories; inspect their contents before treating them as implemented modules or documentation.

## Working Conventions

- Keep early changes focused and avoid introducing infrastructure or client applications outside the requested scope.
- When adding a runnable component, document its local setup, run, test, and lint commands in the relevant README or `docs/` document.
- Keep product and architecture decisions explicit in documentation as the planned Web API, web app, desktop app, and mobile app take shape.
